# Moving Ball Game

## Description
A simple interactive game created using Python and Pygame.

## Features
- Red ball with a radius of 25 pixels
- White background
- Arrow key controls
- Each key press moves the ball by 20 pixels
- Ball cannot move outside the screen

## Controls
- Up Arrow - Move up
- Down Arrow - Move down
- Left Arrow - Move left
- Right Arrow - Move right

## How to Run
```bash
python3 main.py
```
