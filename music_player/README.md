
# Music Player

## Description
A simple music player created using Python and Pygame.

## Features
- Play music
- Stop music
- Next track
- Previous track
- Display current track
- Show playback progress

## Keyboard Controls

| Key | Action |
|---|---|
| P | Play |
| S | Stop |
| N | Next track |
| B | Previous track |
| Q | Quit |

## Requirements
- Python 3
- Pygame

## Installation

pip install pygame

## Run

python main.py
